        How the risk score works

        Only incidents (crimes) are scored; policy, security and deportation news shows as "Update". Points are added when these words appear in the report. 40 or more points = High, 20 or more = Medium. The words and points are set in config.yaml.

        Built with open-source news only. Only headlines, short summaries and links are stored, never full articles.
